# DDNET-AI

Продвинутый ИИ-ассистент для DDNet. Включает в себя мини-игры (рулетка, бомба, дуэли), калькулятор, админ-панель и управление через консоль. Написан на Node.js.

**DDNET-AI** — это продвинутый игровой ассистент для игры DDNet. Бот подключается к серверу как обычный игрок, общается с людьми через нейросети (DeepSeek, Gemini, ChatGPT), развлекает игроков мини-играми и помогает администраторам следить за порядком в чате.

**Имя бота по умолчанию:** `DDNET-AI`

## ✨ Основные возможности

- **🧠 Общение с ИИ:** Просто упомяните имя бота в чате (например, `DDNET-AI привет`), и он ответит вам, используя мощь современных нейросетей.
- **🖥️ Управление из консоли:** Вы можете видеть все логи чата в терминале, а также отправлять сообщения от лица бота (просто напишите текст) или вводить команды сервера (начиная с `/`).
- **🎮 Мини-игры для всех:**
  - `!угадай` — бот загадывает число от 1 до 100, а вы пытаетесь его отгадать (`!число 50`).
  - `!бомба` — передавайте тикающую бомбу другим игрокам (`!передать Ник`), пока она не взорвалась.
  - `!рулетка` — русская рулетка (есть шанс 1 к 6, что бот «взорвет» вас). Есть кулдаун 20 секунд.
  - `!дуэль [ник]` — вызов игрока на дуэль (со ставками очков).
  - `!слоты` — игровой автомат (с шансом сорвать джекпот).
  - `!монетка` — орёл или решка.
  - `!топ` — таблица лидеров по очкам.
- **🛠️ Полезные утилиты:**
  - `!balance` (или `!баланс`) — узнать количество своих очков (очки сохраняются в файл и не сбрасываются при перезапуске).
  - `!say [текст]` — заставить бота повторить любой текст в чате.
  - `!calc [пример]` — встроенный калькулятор (например, `!calc 5*5`).
  - `!roll` — случайное число от 1 до 100.
  - `!time` — узнать текущее время.
  - `!bot [действие]` — заставьте бота что-то сделать (`!bot прыгай`, `!bot налево`).
- **👑 Админ-панель (для владельцев):**
  - `!votekick [ник]` — запустить голосование за кик игрока.
  - `!vote [текст]` — создать любое кастомное голосование.
  - `!clear` — бот замолкает на 30 секунд.
  - `!ignore [ник]` — добавить спамера в чёрный список.
  - `!stop` / `!restart` — выключить или перезагрузить бота.

## 🚀 Как установить и запустить

Для работы бота вам понадобится **Node.js** и программа **browser-ai-bridge** (она связывает бота с сайтом нейросети).

### Шаг 1: Установка Node.js

Если у вас его нет, скачайте и установите с официального сайта: [nodejs.org](https://nodejs.org/) (рекомендуется LTS-версия).

### Шаг 2: Скачивание бота

Скачайте этот репозиторий (нажмите зелёную кнопку `Code` → `Download ZIP` и распакуйте), либо склонируйте через консоль:

```bash
git clone https://github.com/mrraffikss/DDNET-AI.git
```

### Шаг 3: Установка зависимостей

Откройте командную строку (терминал) в папке с ботом и напишите:

```bash
npm install
```

### Шаг 4: Запуск нейросети (мост)

Бот использует вашу открытую вкладку с нейросетью, чтобы отвечать в чате.

1. Откройте второе окно терминала (не закрывайте первое).
2. Напишите команду:

   ```bash
   npx browser-ai-bridge
   ```

3. У вас откроется браузер. Войдите в свой аккаунт DeepSeek (или Gemini). Не закрывайте окно браузера и терминал, пока играете.

### Шаг 5: Запуск самого бота

Вернитесь в первое окно терминала (где папка с ботом) и запустите:

```bash
node ai.js
```

Бот попросит ввести адрес сервера. Напишите IP и порт в формате `IP:порт` и нажмите Enter:

```text
Введите IP:порт (например, 46.174.54.240:8303): 46.174.54.240:8303
```

Готово! Бот подключится к серверу и напишет в чат приветствие.

## ⚙️ Настройка прав и конфига

Откройте файл `ai.js` в любом блокноте. В самом верху вы увидите блок `config`:

```javascript
const config = {
    host: "46.174.54.240",
    port: 8303,
    botNick: "DDNET-AI",     // Ник бота в игре
    bridgeUrl: "http://localhost:3333/api/ask",
    provider: "auto",        // Нейросеть (auto = берет ту, в которую вы вошли)
    defaultPrefix: "!",

    // ПРАВА АДМИНИСТРАТОРА:
    owners: ["Your_Admin_Nick"], // <--- Обязательно поменяйте на свой ник!
    admins: []                   // Ники ваших друзей-модераторов
};
```

**Важно:** По умолчанию права владельца выданы заглушке `Your_Admin_Nick`. Если вы хотите использовать команды `!stop`, `!admin` и другие функции, обязательно впишите свой игровой ник в массив `owners`.

## ⚠️ Важные предупреждения

- **Лимиты нейросетей:** У бесплатных версий DeepSeek и Gemini есть дневные лимиты. Если бот перестанет отвечать (или выдаст ошибку HTTP 500), возможно, вы исчерпали лимит запросов на сегодня.
- **Окно браузера:** Пока бот работает, не закрывайте терминал с `browser-ai-bridge` и окно браузера, в котором открыта нейросеть.
- **Баг с кодировкой:** Если при запуске вы видите кракозябры вместо русских букв, введите в терминале `chcp 65001` перед запуском бота.
